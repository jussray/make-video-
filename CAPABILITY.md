# Make Video | First-party capability contract

Source: jussray/ULTRATHINK- at .claude/skills/juss-af-skills-pack/SKILL.md (v1.0.1).
This is a scoped export of the existing capability contract, not proof of a running renderer.
Governance: load juss-os first; target repo rules prevail when stricter. No inherited authority, evidence, verification, or production status.
Shared stages: INTENT -> AUDIENCE -> TENSION -> CRITERIA -> OPTIONS -> PROOF -> DECISION -> ACTION -> OUTCOME -> LEARNING.
Every claim must be VERIFIED, DEMONSTRATED, QUALIFIED, ASPIRATIONAL, or UNSUPPORTED. Remove unsupported claims. Preserve campaign/asset fingerprints, continuity parent, evidence refs, CTA, and money path. No fabricated reviews, prices, product behavior, or metrics.
A production is not complete without inspecting its rendered output. Report REALITY, FIX, PROOF, RISK, ROLLBACK, NEXT GATE.

## Video-specific contract
Use HOOK -> REAL SITUATION -> INTENT -> DECISION CRITERIA -> PRODUCT/OPTIONS -> PROOF -> SELECTION -> ACTION -> REAL-WORLD OUTCOME when useful, not as a rigid template. Preserve person, wardrobe, environment, product, UI, claim, and CTA state scene to scene. Record scene_id, campaign_id, continuity_parent, evidence_refs, and fingerprint for each scene. Inspect the rendered video, including transitions, audio, captions, and claims, before declaring completion. Publishing requires separate authority.
